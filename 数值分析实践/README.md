# 数值分析实践 · Numerical Analysis Practice

本仓库收录了《数值分析实践》课程（2025–2026 学年第二学期）的全部实验报告、MATLAB 源码与数据可视化结果，使用 **XeLaTeX** 排版，源代码与成品 PDF 一并归档，便于复现与查阅。

> **隐私说明**：为公开分享，仓库内所有报告均已做匿名化处理——真实姓名、学号、班级、指导教师与机位信息一律移除或替换为占位符（姓名以昵称 *VesperaZephyr* 署名，学号使用占位值）。原始文件未做任何改动。

## 目录结构

```
数值分析实践/
├── 01_日常作业/                  # 平时作业（不动点迭代 / 牛顿法专题）
├── 02_实验1_非线性方程求根/        # 不动点迭代、牛顿法、割线法、下山法
├── 03_实验2_线性方程组的求解/      # LU 分解、Jacobi、Gauss-Seidel、SOR
├── 04_实验3_Lagrange插值和Runge现象/ # Lagrange 插值、Runge 现象、Chebyshev 节点
├── 05_实验4_最小二乘拟合/          # 最小二乘线性回归与工程预测
├── 06_实验5_数值积分方法实验/      # 矩形法、梯形法、Simpson 法、Gauss 求积
├── 07_实验6_微分方程数值解法实验/  # 欧拉法、改进欧拉法、RK4
├── 08_综合报告_实验1-2/           # 实验 1、2 合并的完整报告
├── 09_综合报告_实验3-4/           # 实验 3、4 合并的完整报告
├── 10_综合报告_实验5-6/           # 实验 5、6 合并的完整报告
```

每个实验目录内包含：

- `*.tex`：LaTeX 报告源文件（UTF-8 / CRLF）
- `*.pdf`：由对应 `.tex` 编译生成的成品报告
- `*.m`：MATLAB 源码
- `*.png`：实验数据可视化图像

## 实验内容概览

| 编号 | 实验主题 | 核心方法 |
| :--: | :-- | :-- |
| 1 | 非线性方程求根 | 不动点迭代、Newton 迭代、割线法、Newton 下山法；收敛阶与初值敏感性分析 |
| 2 | 线性方程组的求解 | LU 分解（直接法）、Jacobi / Gauss-Seidel / SOR 迭代法；收敛性与效率对比 |
| 3 | Lagrange 插值与 Runge 现象 | Lagrange 插值基函数、等距节点下的 Runge 现象、Chebyshev 节点抑制振荡 |
| 4 | 最小二乘拟合 | 法方程推导、线性回归、残差分析与决定系数 $R^2$、工程寿命预测 |
| 5 | 数值积分 | 矩形法、梯形法、Simpson 法、Gauss 求积；误差—节点数收敛曲线 |
| 6 | 微分方程数值解法 | 显式 Euler、改进 Euler（预测–校正）、四阶 Runge-Kutta；精度与稳定性对比 |
| 综合 | 桥梁振动模态的数值分析与模拟 | 中心差分离散、三对角系统求解（追赶法 / Gauss-Seidel）、三次样条插值、数值积分、扰动敏感性分析 |

## 环境与编译

- **TeX 发行版**：TeX Live 2026（XeLaTeX）
- **字体**：Windows 平台中文字体（SimSun / 宋体），`ctex` 宏包
- **MATLAB**：R2024b（用于生成 `.m` 源码对应的图像结果）

单独编译某份报告：

```bash
xelatex 实验1_非线性方程求根.tex
xelatex 实验1_非线性方程求根.tex   # 再跑一遍以修正目录与交叉引用
```

批量重编译本仓库全部报告：

```bash
python tools/build.py
```

> 含目录或交叉引用的报告需编译 2–3 趟；脚本会自动判断并清理中间产物。
