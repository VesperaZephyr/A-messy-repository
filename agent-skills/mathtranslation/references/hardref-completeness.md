# 交叉引用完整性：防止“编译通过但普遍漏链”

适用于翻译、审校及交付前的交叉引用检查。2026-10 的 Milne 项目暴露了两类具体失效：只扫描“定理/公式/见 + 数字”会漏掉“变量替换 (15)”“形如 (16)”；旧规则把正文单整数公式引用与定义处的 `\tag` 混为一谈，要求保留前者，因而系统性漏链。

## 建立覆盖范围与候选清单

从主文件实际的 `\input` / `\include` 链确定编译文件集合，包括前言、引言、脚注、译注、习题提示及附录。不要扫描备份/OCR 来替代正文。已有转换器只是局部改写工具，其支持的模式不构成完整性标准。

运行 `scripts/audit_bare_references.py <compiled-files...> --output candidates.json`。它只生成带文件、行号、偏移及上下文的候选，不自动修改。覆盖：

- 单整数 `(15)`、小数 `(2.3)`、字母后缀、连续/并列编号、同一列表中只链接第一项的情况。
- 定理、定义、习题等显式名称后的编号，以及没有“见/公式”的裸引用。
- `\S3`（符号后没有空格也要扫描）、`§ 3`、`III, \S2`、`VI.7.2`、中文章/节引用。
- 本书页码与索引页码；外部书籍的定位符必须区别处理。

正确屏蔽已有引用命令、引用键、`\tag` 定义、注释、代码和文献定位参数；不能整块屏蔽数学环境或脚注，公式中的证明引用和译注也可能漏链。扫描器是候选生成器而非完整 TeX 解析器：另外检查宏定义、条件编译、英文 refs、分条 `(a)/(b)` 和间接输入，依据项目补充模式。附加搜索与主清单合并留证，不能用一个窄正则的零匹配证明全书完整。

## 根据真实编号解析目标

读取本次编译的主 AUX **及其输入的各章 AUX**。用平衡花括号解析 `\newlabel`，字段 1 是印刷编号；`1.{9}` 和 `{15}` 需要归一化。字段 4 是 PDF 锚点，不是印刷编号。按目标类型和所属章节/附录建立候选集合，严禁字典赋值覆盖同号目标。

定义处 `\tag{15}` 保持原样；经语义确认的正文 `(15)` 使用 `\eqref{...}`。编号能匹配不等于它是引用：`\Gamma_0(1)`、`f(0)`、坐标 `(0,0)`、小数参数、年份、主理想 `(6)`、局部序号 `(2)` 均可能不是公式引用。带字母后缀的条款只能在确认所属陈述后保留后缀并链接该陈述，或为真实条款建立专用锚点。

对同号多个候选、跨章省略章号、并列引用的后续项，读取上下文及原书确认作用域。缺标签的真实引用应补上目标锚点，再转换；不得以“没有 label”作为永久跳过理由。正常编号对象在标题/环境计数器递增后加 `\label`；手工编号对象在正文标题前放 `\phantomsection\hypertarget{...}{}` 并用 `\hyperlink` 保留原号。不要在错误计数器上添加看似有效的 label。

## 剩余项必须解释，编译通过不是完整性证明

保留修改前清单、实际修改记录和修改后清单。修改后每项标记为：已修复、非引用、外部定位、编号定义、已有链接后缀、刻意引用原书错号，或尚未解决。记录具体理由；不能批量把“未匹配”改标为“非引用”。真实未链接引用应清零；若仍有歧义，报告具体位置及限制，不能宣称全书完成。重复/包含候选可合并，但不能丢失对应位置。

验收至少同时满足：

1. 现有构建流程通过，引用无未定义/重复/缺失目标，原印刷编号未改变。
2. 新引用逐项对应经过确认的编号及目标；PDF 命名目标存在，实际链接跳到该目标所在页和位置。PyMuPDF 可能返回 `LINK_NAMED`，检查其解析后的 `page/to`，不能只统计 `LINK_GOTO`。
3. 复扫清单已逐项处理；检查触发用户反馈的页、并列引用和跨章引用的 PDF 渲染。颜色不能单独证明有链接，链接数量增加也不能证明覆盖完整。

报告分别说明发现/修复的引用数量、剩余候选及原因、目标验证结果；不要把候选匹配次数当作不同引用数量。

原书页码引用必须定位到原页的具体段落再建译文锚点；不能把原书 p.55 / p.86 随手改成猜测的章节号。只有章节号匹配并不能证明跳到了原引用内容。

枚举项的 AUX 印刷编号可能已经包含括号，例如 \textup{(2)}；显示 \ref*{item} 时不要再包一层括号。链接文本应以实际输出核验，避免把 (2) 变成 ((2))。

更新后的 convert_bare_refs.py 仅在未屏蔽的正文执行通用匹配，数学环境、绘图、已有链接和外部文献定位符受保护；这些区域中的真实引用仍由独立扫描器列出，再经核实用 EXACT 或定点修改补齐。EXACT 计数不符时禁止写回任何文件，不允许带警告继续替换。
