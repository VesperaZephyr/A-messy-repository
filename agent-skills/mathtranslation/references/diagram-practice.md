# 交换图专项：规格、练习与独立复核

用于新绘、修复或重点审阅交换图。这里的“训练”是任务前的校准练习及回归样例，
不是调整模型权重；通过练习不能替代本书逐图核查。
如安装了 `latex-array-diagram-audit`，同时读取其入口与相关验证说明；未安装时
仍执行本文的节点/边规格与最终页检查，不因跨技能路径不存在而跳过。

## 从原图独立恢复规格

先看原书整页定位，再放大图及箭头端部。记录物理页、裁剪框、图前后文字与原书哈希。
建立两份独立清单：原图规格由原书恢复，译图规格由 TeX（展开相关宏）与编译图恢复。
审阅者第一份清单完成前不看作者给出的边表。

```text
diagram_id:
nodes: [{id: A, row: 1, col: 1, tex: "A"}, ...]
empty_cells: [...]
edges: [{id: e1, source: A, target: B, geometry: right,
         head: single, tail: hook, stroke: solid, label: "i",
         label_side: above, bend: none, evidence: "page/bbox"}, ...]
special: {parallel_edges: ..., crossing_or_junction: ..., zero_rows: ...}
unresolved: [...]
```

逐项核对节点（含零、空格位）、端点、实际数学方向、箭头两端样式、虚实线、
标签与侧别、弯曲/平行边、交叉线是否相连。原书的普通箭头不能因推测单射而添加钩。
结构差异先于美化；数学上“应该如此”只作为疑点，不覆盖原书。
交换性由原书陈述/标记支持，不能从一个好看的方形或节点排布自行证明。

## 易错样例：先预测，后编译观察

| 校准题 | 应识别的区别 |
|---|---|
| `A \arrow[r,hook,"i"] & B` 与 `A \arrow[r,"\hookrightarrow"] & B` | 后者标签是钩箭头字形，边本身仍是普通箭头 |
| `hook` 与 `hook'` | 钩侧别变化；不能据此认定映射反向 |
| `two heads` 与普通头 | 满射双头应在目标端真实出现 |
| `dash`、`dashed`、`equal` | 无头实线、有向虚线、双线不是同一关系 |
| 从右侧单元格 `\arrow[l]` | 先定位当前节点，再判断左侧目标，不能按阅读顺序猜 |
| 局部 `hook, rightarrow` 与全局 `every arrow` 覆盖 | 以最终渲染的头/尾为准；查关键词不够 |
| `0 → A → B` 缺掉左侧 `0`；两行图漏整行 | 编译和剩余边的正确性不能证明结构完整 |
| 两条平行反向箭头，或带对角虚线的拉回图 | 分开记录端点、偏移、标签侧与虚实，不能合为一条边 |

这些是需要植入并识别的缺陷类型。评估独立审阅者时只给有问题的原图/译图对，
不要给出上表的答案或提示。保留“发现了哪些 / 漏掉哪些”的实测结果。

## TikZ-CD 实施

用 `tikzcd`，不以截图交付交换图；可截图作为原书证据。复杂结构优先显式
`from=1-1,to=2-2`，避免改节点后相对方向悄悄改变。保留原书空位与零行。
先用最小样例验证，再放回真实文档检查类文件、`\tikzcdset` 与宏的全局覆盖。
例如单射—满射短列的最小样例（它只是校准样例，不能套写本书的所有短列）：

```latex
\documentclass{article}
\usepackage{tikz-cd}
\begin{document}
\[
\begin{tikzcd}
0 \arrow[r] & A \arrow[r,hook,"i"] & B \arrow[r,two heads,"p"] & C \arrow[r] & 0
\end{tikzcd}
\]
\end{document}
```

逐边给出 `结构已核查 / PDF 几何已核查 / 已直接目视 / 未决` 的证据状态。
放大端部确认微小钩与双头，再按书页实际尺寸检查标签碰撞、裁断与可读性。
没有可用的图像查看能力时继续文字/向量分析，但不得把它记为直接目视通过。
