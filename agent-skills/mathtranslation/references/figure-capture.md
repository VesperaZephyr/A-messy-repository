# 插图实操：PDF 裁切、截图与 TikZ 重绘

原生 PDF 的“截图”优先解释为直接渲染指定物理页/区域，不必操纵阅读器截图。
先确认需求：忠实复用、可编辑重绘、还是只取得审阅证据。交换图最终交付用 tikzcd；
一般几何图按 `illustrations.md` 选择矢量裁切、TikZ/PGFPlots 或保留扫描图。

## 不靠猜测的截图路径

1. 检查可用 Python 及 `import pymupdf`，并确认
   `callable(getattr(pymupdf.Page, 'remove_rotation', None))`；不假定旧机器路径仍可用。
   缺少该接口时更新 PyMuPDF 或改用现成渲染工具，脚本会明确报错而不继续错裁。
2. 先导出整页预览；使用 **PDF 文件从 1 开始的物理页**，与印刷页码分开记录。
3. 用图像工具实际打开预览（Codex 可用 `view_image` 时使用它）。工具返回路径不等于看过图。
4. 根据该预览量取框，重新导出局部。本文脚本的 bbox 是 **旋转后的可见页坐标**，
   原点左上，x 向右、y 向下，单位 pt（72 pt = 1 inch）；不是 PDF 原始底左坐标。
   整页预览的像素转点：`x_pt = x_px * page_width_pt / preview_width_px`，y 同理。
   勿在缩放后的聊天缩略图上直接量原图像素；先确认原图尺寸。
5. 检查四边、所有面板、远处标签、箭头头及上下标；不要只看主轮廓。
   裁切框来自检查，不能从 Fig. 字样上方一段固定高度或“最大图形”直接定稿。

随附 `scripts/capture_pdf_region.py`，依赖 PyMuPDF，无桌面截图依赖：

```powershell
python '<skill-dir>/scripts/capture_pdf_region.py' '原书.pdf' --page 17 --out 'evidence/page17' --dpi 120
python '<skill-dir>/scripts/capture_pdf_region.py' '原书.pdf' --page 17 --bbox 72 110 490 360 --out 'figures/fig-2-3' --dpi 300
```

每次生成 `.pdf`（裁切容器）、`.png`（目视预览）和 `.json`（来源哈希、页码、bbox、尺寸、状态）。
脚本用 show_pdf_page 保留可复用的 PDF 内容；扫描页仍是扫描图，不因保存为 PDF 就成为矢量。
状态初始为 `exported_unreviewed`，人工/代理核查结果另存图清单，不自动认证裁切正确。
导出不包含 PDF 批注与表单外观；JSON 记录批注数。原图依赖这些可见内容时，
先取得保留其外观的副本或另选渲染方式，并与原始整页比较，不能漏掉后仍认证完整。
拒绝越界/空框和已有输出；需要替换时显式 `--overwrite`。不会自动白边裁切，避免丢细线。
加密 PDF 先获得可访问副本；不要把口令放入交接包或命令输出。

若没有 PyMuPDF，使用现成 PDF 渲染工具（如 pdftoppm）先出整页，再按已确认框裁切。
只有网页画布或无法取得文件时才使用可用浏览器截图接口，并记录缩放与页面状态。
工具失败先检查绝对路径、文件大小、退出码及图像打开方式；一次失败不证明没有视觉。
若工具/依赖确实不可用，明确记录缺口，继续可以验证的结构工作，不假装截图已完成。

## TikZ/PGFPlots 重绘策略

- 先列数学不变量：点/线/面、函数或参数、坐标范围、方向、边界含开闭、遮挡、
  对称/比例与面板关系。只有图上画出的关系才是重绘要求，不凭美观改变拓扑。
- 优先函数/参数曲线；不明函数用经原图核对的控制点近似并记录限制。
  奇点分段画，避免采样连线跨过渐近线；坐标比例有数学意义时固定比例。
- 几何与文字分开组织节点；中文标签用项目引擎/字体。保持标签和符号对应，不把标签烘焙进位图。
- 最小 TeX 样例先编译检查，再并入书稿。模型无法可靠恢复复杂扫描几何时保留原图并报告，
  不以“TikZ 可编译”认证几何正确。用户明确要求重绘时，裁切图只作参考，不能充当已完成重绘。
- 复用裁切 PDF 通常配 `\includegraphics[width=...\linewidth]{...pdf}`；TikZ 避免整体缩放到
  标签失读，优先调整坐标间距、面板布局和字体。两者都要检查最终书页与实际标签大小。

交付前对照原书整页、独立资产和最终页三处；保存源/译物理页映射及逐图结论。
